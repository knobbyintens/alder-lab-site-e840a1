# Molecule Graph Distillation - Official Code

Status: **Released** - v1.2 (2025-08-14)

Reference implementation of "Molecule Graph Distillation with
Structure-Preserving Coarsening" (JASR 2025).

## Install

```
pip install -e .
```

The v1.2 release contains the full training and evaluation code, pretrained
weights for the three benchmarks reported in the paper, and reproduction
scripts. Issues and pull requests are welcome.
